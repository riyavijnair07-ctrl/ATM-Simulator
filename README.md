# ATM-Simulator
ATM Simulator — Python A simple ATM Simulator developed using Python. This project is designed for beginners and demonstrates basic programming concepts such as variables, conditional statements, loops, functions, input validation, and string handling.
🔐 PIN authentication
🚫 Maximum 3 PIN attempts
💰 Check account balance
💵 Deposit money
🏧 Withdraw money
🔑 Change PIN
⚠️ Insufficient balance checking
✅ Invalid input handling
❌ Exit option
🛠️ Technologies Used
Python 3
Python built-in functions
No external libraries required
🔑 Default Details
PIN: 1234
Starting Balance: ₹10,000

- How to Run
1. Install Python
Make sure Python 3 is installed on your computer.
2. Download/clone the project
git clone YOUR_GITHUB_REPOSITORY_LINK
3. Open the project folder
cd ATM-Simulator
4. Run the program
python atm_simulator.py
